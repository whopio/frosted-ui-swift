# icons-allowlist.txt
#
# Base icon names (one per line, size suffix stripped) that ship in
# Icons.xcassets. Every other imageset is deleted by bin/trim_icons.sh so the
# compiled Assets.car only carries icons that consumers actually reference.
#
# Icons.xcassets holds one imageset per size (12/16/20/24/32) of every base.
# The full Figma set is ~5,000 imagesets; the whop apps use ~231 bases. Trimming
# to this allowlist roughly halves the compiled catalog.
#
# Because FrostedIcon (and the FrostedIconSet presets) are generated from the
# imagesets present on disk, a trimmed icon becomes a compile error the moment a
# consumer references it. There is no runtime fallback: the allowlist IS the
# enforcement.
#
# To add an icon:
#   1. Add its base name below (keep the list sorted).
#   2. Run: ./bin/trim_icons.sh
#      (re-downloads nothing; deletes non-allowlisted imagesets, then
#       regenerates Icon+Extensions.swift). If the base was never downloaded,
#       run ./bin/generate_frosted_icons.sh first to pull the full set.
#   3. Commit the allowlist change, the surviving imagesets, and the regenerated
#      Icon+Extensions.swift together.
#
# Comment lines (starting with #) and blank lines are ignored.
